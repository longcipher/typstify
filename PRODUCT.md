# Product

## Register

product

## Users

Developers and technical writers building blogs, documentation sites, and knowledge bases. They value performance, type safety, and Typst's typesetting quality. They're comfortable with CLI tools and Rust ecosystems.

## Product Purpose

Typstify is a high-performance static site generator that gives developers first-class Typst and Markdown support with built-in full-text search (Tantivy + WASM). It exists to fill the gap between Hugo/Zola's Markdown-only approach and Typst's superior typesetting — delivering a single-binary tool that's fast, correct, and extensible.

## Brand Personality

Precise, minimal, correct. Think Rust's ethos applied to site generation: no bloat, no magic, clear abstractions. The voice is confident but not loud — technical precision over marketing enthusiasm.

## Anti-references

- Generic AI-generated UI: cream/sand backgrounds, gradient text, identical card grids, glassmorphism
- SaaS dashboard aesthetics: heavy gradients, metric-heavy hero sections, decorative side-stripe borders
- Dense admin panels: cluttered interfaces with too many visible options
- Over-styled developer tools: skeuomorphic terminal themes, excessive decoration on code blocks

## Design Principles

1. **Content is the product** — the generated site is what users care about; the tool itself should disappear
2. **Correctness over decoration** — every visual choice should serve function; remove anything that doesn't help the user read, write, or navigate
3. **Developer-grade clarity** — information hierarchy that rewards scanning; precise labels over clever copy
4. **Minimal footprint** — small bundles, fast builds, lean CSS; the tool should feel as fast as it is
5. **Extensible, not opinionated** — users should be able to override themes and styles without fighting the system

## Accessibility & Inclusion

WCAG AA compliance. Standard keyboard navigation and screen reader support. Reduced motion preferences respected in any future animations. Color contrast verified for all text-on-background combinations.
