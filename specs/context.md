## Code Conventions

- **Naming:** snake_case for functions/variables, PascalCase for types, SCREAMING_SNAKE for constants
- **Error Handling:** `eyre` at application layer, `thiserror` at library layer
- **State Management:** Ownership-based, `Config` cloned into generators
- **Import Style:** grouped stdlib/external/local, `use crate::` for intra-crate
- **Error Propagation:** `?` operator, custom `Error` enums per crate
- **Testing:** `#[cfg(test)]` colocated, `tempfile::TempDir` for filesystem tests

## Architectural Decisions (Existing)

- AGENTS.md: hpx over reqwest, scc over dashmap, winnow over manual parsing, thiserror at library layer, eyre at app layer
- Workspace uses `cargo add` for dependency management
- `Config` is `Clone` and passed by value into generators (multiple clones in build pipeline)
- Template engine is custom (`{{ variable }}` replacement, no auto-escaping)
- Search has two backends: SimpleSearchIndex (substring, always used) and SearchIndexer (Tantivy, built but unreachable)
